# numerology-finance-calendar

Генератор персонального финансового календаря по дате рождения на основе нумерологии.

![Tests](https://img.shields.io/badge/tests-17%2F17-brightgreen.svg)

## Что это

Проект рассчитывает **число жизненного пути** и **числа силы** по дате рождения и определяет, какие дни месяца благоприятны для финансовых операций (накопления, оплаты, крупные покупки, лотерея), а какие — табу.

> **Разница понятий:**
> - **Число жизненного пути** — ОДНА цифра (1–9, 11, 22, 33). Считается сложением всех цифр даты.
> - **Числа силы** — НАБОР цифр, благоприятных для конкретного человека. Включают день рождения, число пути, составляющие цифры.

```bash
$ python scripts/generate_calendar.py --birthdate 1990-05-15 --today

=== 2026-08-17 (понедельник) ===
Дата рождения: 1990-05-15
Число жизненного пути: 3
Числа силы: [1, 3, 5, 15]

❌ ДЕНЬ-ТАБУ

Нельзя:
  - Оплата подписок
  - Крупная покупка
```

## Канон нумерологии

### Алгоритм расчёта числа жизненного пути

Используется классическая система нумерологии Пифагора:

1. Записываем полную дату рождения (день, месяц, год).
2. Складываем все цифры.
3. Если получилось двузначное число — складываем его цифры.
4. **Мастер-числа 11, 22, 33 не сводятся** — это их суть.

**Пример:** 1990-05-15 → 1+5+0+5+1+9+9+0 = 30 → 3+0 = **3**.

Источник: [Нумерология — Wikipedia](https://ru.wikipedia.org/wiki/Нумерология).

### Значения чисел 1–9

| Число | Значение |
|---|---|
| 1 | Лидер, новатор, независимый и сильный человек |
| 2 | Миротворец, дипломат, ценит партнёрство и гармонию |
| 3 | Оптимист, творческая личность, общительный и яркий человек |
| 4 | Труженик, надёжный и практичный организатор порядка |
| 5 | Любитель свободы, перемен и новых приключений |
| 6 | Защитник, преданный семье, заботливый и ответственный |
| 7 | Мыслитель, исследователь, ищет скрытый смысл и мудрость |
| 8 | Стратег, силён в бизнесе, финансах и материальном успехе |
| 9 | Гуманист, мечтатель, стремится помочь всему миру |

Эти значения помогают интерпретировать, **почему** именно эти числа попали в твои «числа силы». Например, если в числах силы оказалась 8 — это «сила материального успеха». Если 7 — «сила мудрости и анализа».

### Числа силы

В проект входят следующие числа силы:
- **День рождения** (например, 27).
- **Число жизненного пути** (например, 11).
- **Составляющие цифры дня рождения** (для 27 → 2 и 7).
- **Цифры месяца рождения** (для 02 → 2).
- **Цифры числа жизненного пути, если оно не мастер-число** (для не-мастер-чисел).
- Дополнительные числа, заданные пользователем вручную.

### Правила для финансовых операций

**Важно:** правила good/bad для финансовых операций **не имеют единого канона** в нумерологии. Разные школы и авторы дают **противоречивые рекомендации**.

**Пример противоречия:**

| Аспект | Синтез автора (этот проект) | Другая точка зрения |
|---|---|---|
| Самые «денежные» числа | 7, 11, 27 | 6, 8, 9 |
| Число 5 | табу (риск, потери) | «не всегда удачное» |
| Число 8 | табу (потери в кредитных операциях) | «один из лучших для денег» |

**Вывод:** правила по умолчанию в `rules/default-rules.json` — это **синтез автора**, основанный на личном опыте и опыте консультантов. Пользователь может отредактировать файл и подобрать правила под свою систему убеждений.

## Использование как модуль

```python
from datetime import date
from numerology import life_path_number, power_numbers, load_rules, day_for_date

birth = date(1950, 4, 19)
lp = life_path_number(birth)                       # 11
pn = power_numbers(birth, lp)                     # [1, 4, 9, 11, 19]
rules = load_rules("rules/default-rules.json")
today = day_for_date(date.today(), rules)

print(f"Сегодня ({date.today()}):")
print(f"  Хорошо: {today.good}")
print(f"  Плохо: {today.bad}")
print(f"  Нейтрально: {today.neutral}")
```

15 тестов покрывают:

- статус конкретного дня.

## Известные ограничения

1. **Нумерология — не доказательная наука.** Это система убеждений, а не научный метод. Используйте проект ответственно.
2. **Правила good/bad не выводятся из даты рождения автоматически.** Они задаются в `rules/default-rules.json` и могут быть отредактированы.
3. **Не учитывается влияние планет и лунного календаря.** Только арифметика даты рождения.
4. **Мастер-числа 22 и 33 не всегда получаются из арифметики.** Например, 2000-11-22 даёт 8, а не 22. Это намеренное поведение: мастер-число «дано» в дате рождения.

## Что НЕ входит в проект

- **Telegram-интеграция с реальным каналом.** Скрипт `scripts/generate_calendar.py` только печатает календарь в консоль. Для автоматической отправки в Telegram нужен отдельный `post_to_telegram.py` — он не включён в репо, так как содержит BotGate-ключ (приватный).
- **Веб-интерфейс.** Только CLI.
- **Хранение истории постов.** Только расчёт на дату.

Пифагорейская школа (VI век до н. э.) — Пифагор учил, что числа управляют миром, всё сводится к 1–9, мастер-числа 11, 22, 33 не сводятся.

- [Numerology — Wikipedia](https://en.wikipedia.org/wiki/Numerology)

### Правила для финансовых операций

**В нумерологии нет единого канона** для привязки чисел к финансам. Используемая в проекте таблица (`rules/default-rules.json`) — авторский синтез на основе:

- пифагорейской традиции (числа дня, месяца, года);
- ведической нумерологии (Джйотиш) — идея о значимости числа дня рождения для характера;
- практического опыта нумерологов-консультантов (какие числа они чаще помечают «денежными»).

**Где углубиться самостоятельно** (книги на русском и английском):

- Александр Колесников — «Нумерология. Полная система».
- David A. Phillips — «The Complete Book of Numerology».
- Линн Бакстон — «Нумерология: цифры вашей судьбы».

**Важно понимать:** нумерология — псевдонаука. Это инструмент для саморефлексии (как астрология или метафорические карты), а не доказательный метод. Если правила проекта не работают для тебя — отредактируй `rules/default-rules.json` под свою систему убеждений.
