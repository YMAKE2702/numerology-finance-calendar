# numerology-finance-calendar

Этот скилл помогает Claude Code работать с проектом `numerology-finance-calendar` — генератором финансового календаря по нумерологии.

## Когда вызывать этот скилл

Когда пользователь:
- просит «составь финансовый календарь на месяц» с указанием даты рождения;
- спрашивает «сегодня хороший день для покупки / накоплений / оплаты»;
- просит объяснить, что такое «числа силы» и «день жизненного пути»;
- хочет изменить правила (`rules/default-rules.json`) и понять, как они применяются;
- просит написать тесты для модуля `numerology/`.

## Что умеет проект

1. **Считать число жизненного пути** по дате рождения через `numerology.life_path.life_path_number()`.
   - Поддерживает мастер-числа 11, 22, 33 (не сводятся).
2. **Считать числа силы** через `numerology.power_numbers.power_numbers()`.
   - По умолчанию: день рождения, число пути, составляющие цифры, цифры месяца.
3. **Определять статус дня** через `numerology.calendar.day_kind()`:
   - день силы (есть «хорошие» операции),
   - день-табу (есть «плохие» операции),
   - нейтральный день.
4. **Генерировать календарь на месяц** через `numerology.calendar.generate_month()`.
5. **CLI-обёртка** в `scripts/generate_calendar.py` — печатает календарь в консоль.

## Как использовать CLI

```bash
# Календарь на конкретный месяц
python scripts/generate_calendar.py --birthdate 1980-02-27 --month 2026-08

# Статус на сегодня
python scripts/generate_calendar.py --birthdate 1980-02-27 --today

# С пользовательскими правилами
python scripts/generate_calendar.py --birthdate 1980-02-27 --rules ./my-rules.json --today
```

## Как использовать как модуль Python

```python
from datetime import date
from numerology import life_path_number, power_numbers, load_rules, day_for_date

birth = date(1980, 2, 27)
lp = life_path_number(birth)                       # 11
pn = power_numbers(birth, lp)                     # [2, 7, 11, 27]
rules = load_rules("rules/default-rules.json")
today = day_for_date(date.today(), rules)
print(today.good, today.bad, today.neutral)
```

## Тестирование

```bash
python -m unittest tests.test_numerology -v
```

15 тестов покрывают:
- распознавание мастер-чисел (11, 22, 33),
- расчёт чисел силы для известных дат,
- классификацию дней (good / bad / neutral),
- генерацию календаря на месяц.

## Известные ограничения

1. **Правила «good/bad» не выводятся из нумерологии автоматически.** Они задаются в `rules/default-rules.json` по классической нумерологии и могут быть отредактированы пользователем.
2. **Не учитывается влияние планет и лунного календаря.** Только арифметика даты рождения.
3. **Мастер-числа 22 и 33 не всегда получаются из арифметики.** Например, 2000-11-22 даёт 8, а не 22. Это намеренное поведение: мастер-число должно быть «дано» в дате рождения.

## Что НЕ нужно делать

- Не публиковать в репо реальные данные пользователей (имена, даты рождения).
- Не выдавать результат за «научный прогноз». Это нумерология — система убеждений, а не доказательная наука.
- Не модифицировать `rules/default-rules.json` без явного запроса пользователя.
